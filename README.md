
# Interactive Venue Ticketing System

## Project Overview

This is my project I created online booking site for theatre tickets using HTML, CSS, and JavaScript.

The users will be able to tour the theatre, view the seats, add the tickets into the cart, and view the total cost.

## Venue Information

The theatre has 144 seats and divided into three sections:

- VIP: 48 seats, 45 AZN each
- Standard: 48 seats, 30 AZN each
- Economy: 48 seats, 20 AZN each

Each section has 4 rows with 12 seats per row.

## Main Features

The seats are generated by JavaScript.

There are four seat types:
- Green: Available
- Orange: Selected for inspection
- Blue: Added to cart
- Grey: Unavailable

When users click on a seat, they can see its section, row, seat number, and price before adding it to the cart.

The website also allows users to:
- Add tickets to the shopping cart
- Remove tickets from the cart
- See the total ticket price automatically
- Avoid adding the same ticket twice
- Keep their cart saved using localStorage

## Map Controls and Bonus Features

You can zoom in, zoom out, move the map up, down, left or right and reset the map.

I also added two bonus features:
- Mouse wheel zoom
- Click and drag map navigation

The website has a responsive design for both desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Browser localStorage

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Click on a seat to see its details and price.
5. Click ADD TO CART to add the selected ticket.
6. Use Remove to delete a ticket from the cart.

No additional installation is needed.

## Project Files

- index.html - Website structure
- style.css - Website design and responsive layout
- script.js - Seat generation, navigation, and cart logic
